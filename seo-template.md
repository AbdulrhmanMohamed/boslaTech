## 9. Technical SEO (Framework Ch. 13)

### 9.1 Crawlability & Indexability

- [ ] Robots.txt correctly configured (not blocking important pages)
- [ ] XML Sitemap submitted to GSC
- [ ] No orphan pages (every page has 3+ internal links)
- [ ] Meta robots = index, follow on all important pages
- [ ] Canonical tags set correctly (self-referencing)
- [ ] No broken links (404s)
- [ ] No redirect chains (> 3 hops)
- [ ] hreflang tags correct (if multi-language)
- [ ] All CSS/JS accessible to Googlebot

### 9.2 Core Web Vitals

| Metric | Target | Current | Action |
|--------|--------|---------|--------|
| LCP | < 2.5s | | |
| INP | < 200ms | | |
| CLS | < 0.1 | | |

- [ ] Images optimized (WebP/AVIF, compressed)
- [ ] CDN configured
- [ ] Render-blocking resources deferred/async
- [ ] Fonts use `font-display: swap`
- [ ] Image/video dimensions set (width + height or aspect-ratio)
- [ ] Lazy loading for below-fold images

### 9.3 Mobile Optimization

- [ ] Responsive design
- [ ] Font size ≥ 16px on mobile
- [ ] Touch targets ≥ 48×48px
- [ ] No intrusive interstitials
- [ ] Viewport meta tag present
- [ ] Passes Google Mobile-Friendly Test

### 9.4 Security

- [ ] HTTPS + valid SSL certificate
- [ ] HSTS header configured
- [ ] Content Security Policy (CSP) set
- [ ] No mixed content warnings

### 9.5 Schema (Structured Data)

- [ ] LocalBusiness (homepage + location pages)
- [ ] Service (each service page)
- [ ] Article (each blog post)
- [ ] BreadcrumbList (every page)
- [ ] FAQPage (FAQ section)
- [ ] Product (ecommerce products)
- [ ] Review (testimonials)
- [ ] HowTo (instructional content)
- [ ] All schema validates in Rich Results Test

## 18. Pre-Publishing Checklist (Every New Page)

- [ ] Intent matches keyword
- [ ] Primary entity in first 100 words
- [ ] Secondary entities mentioned naturally
- [ ] All expected questions answered
- [ ] 3+ internal links
- [ ] Structured data installed
- [ ] Meta title + description optimized
- [ ] Clean, descriptive URL
- [ ] H1 clear with primary entity
- [ ] Heading hierarchy correct (H1 → H2 → H3)
- [ ] Images optimized (Alt, size, format WebP/AVIF)
- [ ] Core Web Vitals pass
- [ ] Mobile-friendly
- [ ] Clear CTA
- [ ] No duplicate content
- [ ] Canonical tag correct
- [ ] Indexing allowed (meta robots = index, follow)

## Post-Publishing Checklist

- [ ] Request indexing via GSC URL Inspection
- [ ] Confirm indexing after 24-48h
- [ ] Add internal links from existing pages
- [ ] Add to sitemap (if manual)
- [ ] Add to rank tracker
- [ ] Monitor performance for 2 weeks
- [ ] Analyze: impressions, clicks, CTR, avg position
- [ ] Refresh content if performance is weak
